# PRODUCT.md — TeX写作智能体（codebuddy-prism）

## What this is

AI 原生的协作 LaTeX 写作平台（Aldine fork，AGPL-3.0）：实时协同、git 分支、
远程仓库同步、文献管理、评审批注、编译预览、prism 风格 AI 写作助手。
浏览器即写作环境，中文开箱（默认 XeLaTeX + ctex + 内置中文字体）。

## Audience

- 主受众：国内高校毕业生（2026 年 1270 万/年量级）、课题组的导师与学生——
  学位论文、课题组论文、期刊/会议投稿、课程报告。
- 次受众：自托管机构（校园网私有部署，数据不出网）。

## Promise

论文项目天然是 git 仓库：分支并行、一键合并、导师批注留痕；AI 助手直接
读稿、改稿、编译、提交，每次改动以 diff 呈现、一键保留或撤销——作者始终
掌控成稿。配置零门槛，中文从第一行起正常渲染。

## Visual world

深海军蓝「科技黑」世界（--bg-app #12141c、面板 #1a1c24、单一紫罗兰强调
--accent-fill #6c5ce7），Manrope（display）+ Inter（UI）自托管，暗色为默认
主题。全部 tokens 见 `src/theme.css`。营销面（落地页）沿用同一世界，可加
落地页专属语法（胶囊 CTA、等宽眉标、浏览器框截图），不回写应用 UI。
